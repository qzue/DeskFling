# Windows x64 开发构建与运行

## 当前 W3 快捷方式副本不带箭头（2026-11-13）

按用户选择，预览副本不再合成快捷方式箭头：通过同快照 PIDL 的 `SFGAO_LINK` 属性判定快捷方式，提取主图标时不应用其叠加掩码。非快捷方式继续保留原有叠加逻辑。只改自有缓存图像，不删除图像像素、不改真实桌面图标或系统设置。

主图标仍采用系统图像列表实际 60×60 像素（当前配置），带入上一次报告中用户选定的统一下移 **5 个屏幕像素**。静态上下微调、对照、独立停止仍保留。报告分别记录快捷方式属性、去箭头策略和实际省略数量，未进行的显示验收仍待用户确认。下方旧默认偏移值与带箭头策略为历史。


## 当前 W3 统一垂直微调（2026-11-13）

用户确认系统图像列表版大小正常，报告实际 60×60 像素 / 120 DPI；反馈所有副本稍高并要求统一向下移。本版保持尺寸、取图和原始 Shell 锚点不变，仅默认给副本增加 +4 个屏幕像素的人工 Y 偏移。静态阶段可用“上移/下移 1 像素”按钮统一调整，范围 -16～+16，每次调整清除静态确认；播放和停止后禁用调整。缓存图片不会重读或重建纹理。

偏移通过共享坐标函数换算，不逐项补偿；报告原始坐标与人工偏移分开，仍不声称自动精确定位或取得 Explorer 图像边界。偏移只用于本次预览，不写系统设置或应用偏好。确认后重力和重置使用相同的副本初始位置。下方为历史。


## 当前 W3 系统图像列表修订（2026-11-13）

上一版把视图返回的 48 当作最终物理像素，用户实测明显偏小：实际 120 DPI 的副本画成 38.4 DIP/48 像素。该修订的视觉结果未通过。

本版针对已有限制的标准图标视图（GetViewModeAndIconSize 返回 FVM_ICON/48），另读 `SHGetImageList(SHIL_EXTRALARGE)` 的 `IImageList::GetIconSize`，使用系统图像列表实际宽高，不手工乘固定倍率。其他视图设置暂时只显示标记。取得此值不等于证明 Explorer 图像精确边界。

同快照的父/子 PIDL 组成完整 PIDL，通过 `SHGetFileInfo(SHGFI_PIDL)` 取得系统图像索引，再从同一图像列表复制 HICON（包含可取得的叠加标记），转为缓存的预乘位图。原图像工厂的通用文件样式不再作为该预览的成功副本。没有按名称/路径匹配、改动系统图像列表或创建占位图。失败时保留标记，不开放副本。

初始化即创建脱敏 `<报告路径>.initialized.json`，记录本次 DPI、视图设置、系统图像列表实际尺寸和图像阶段；关闭时仍写完整报告。两者都拒绝覆盖已有文件。这让尺寸错误无需等面板关闭即可诊断，不包含图像、名称或私人路径。静态对照和独立停止保留，精确贴合仍待实测。下文前版取样策略为历史。


## 当前 W3 画质修订

副本现在读取 `IFolderView2::GetViewModeAndIconSize` 报告的像素尺寸，沿用同快照 PIDL 获取图像并缓存；不再固定 48 DIP。实际位图宽高会记录，用共享坐标函数换算为 DIP、等比例缩小且不放大低分辨率位图。图像保持完整透明边距，不裁剪后猜测偏移；采用高质量三次插值。Shell 项目锚点仍不代表精确图像边界，位置只是一致的 DPP 放置规则，精确对齐待实机核对。

静态副本阶段可点“对照：仅看原图标”清除本程序副本，再点“对照：显示副本”恢复。只改变本程序绘制，不改变真实图标。大号 DPP 文字和绿色全框改为图像角内小编号，编号对应控制面板列表。先比较尺寸、边缘和位置；有问题选“不符合”后保存停止，不进入重力或交互。原图标保留，无法承诺消除重影。下方旧版尺寸和操作记录为历史。

本入口构建共享核心、共享自动化测试、Win32/Direct2D 沙盒和只读 Shell 探针。正式真实桌面模式保持禁用；编译、单测与开发 ZIP 不代表登录桌面交互、Shell 布局、透明合成、GPU 或持久恢复验收。

## 构建

需要 Windows x64、PowerShell 7、Visual Studio 2022 C++ Build Tools（含 Windows SDK）、CMake >=3.25：

```powershell
pwsh -NoProfile -File "./scripts/build-windows.ps1"
```

脚本复用 `windows-msvc` 的 Visual Studio 17 2022 / x64 预设，由生成器定位 MSVC，不假定普通 PowerShell 有 Ninja + MSVC 编译环境。工具路径有空格时使用 PowerShell 调用运算符与独立参数；便携 CMake 的 bin 目录可加入本次进程 PATH。

每次建立独立的 `out/windows-<UUID>/`。按白名单复制实际输入（包括未提交源码），拒绝符号链接，记录每个文件的 SHA256。`artifacts/source-inputs.json` 的 SHA256 是输入标识，不是 Git commit；`source/` 保留实际构建副本。Box2D 固定 vendored v3.1.1；GoogleTest 1.15.2 下载或本地压缩包均验证锁定哈希。

顺序：配置 → Debug 全目标构建 → Debug CTest → Release 全目标构建 → Release CTest → 独立 staging 安装 → dumpbin 架构/依赖检查 → 开发 ZIP 和 SHA256。非零退出或无测试均停止；失败不生成成功 ZIP。共享测试完整保留，macOS 专属测试仅在 APPLE 分支加入。

`artifacts/` 保存构建清单、逐文件输入哈希、构建/测试日志、JUnit 和包哈希；失败保存 failure.json。ZIP 只包含安装后的程序、许可、本文和输入/构建清单，不包含真实桌面证据、偏好、图像、密钥或源码快照。使用静态 MSVC CRT，实际依赖见 dumpbin 输出。开发包未签名，不是正式发布。

## 运行与 W2 边界

解压后，沙盒入口为 `bin/physics_sandbox.exe`，只读探针为 `bin/desktop_probe.exe`。沙盒使用合成几何，无开发者本机图像路径依赖。Space 暂停/继续、R 重置、B 切换模式、Esc 退出；鼠标拖拽与释放用于抓取/抛掷。

构建脚本不会自动启动这两个程序。仅在可实际操作的登录桌面中，单独验证沙盒交互及退出，再核对只读探针的当前 Shell 视图、项目覆盖和失败 HRESULT。SSH 会话或 CI 单测不能替代 W2。不得为此隐藏图标、改布局、修改 Explorer 或执行恢复破坏测试。

## 只读 Shell 样本检查（显式开启）

默认 `desktop_probe.exe` 仍只输出汇总计数，不打开样本窗口、不导出报告。`--help` 列出实际参数。样本模式必须在普通登录用户桌面运行：

```powershell
& .\bin\desktop_probe.exe --samples 5 --report "$env:TEMP\dpp-samples-$([guid]::NewGuid().ToString('N')).json"
```

`--samples` 接受 3、4、5；`--report` 必须指定新文件，已存在时拒绝覆盖。窗口逐项显示本次快照 S1～S5 的名称、图像和原始位置，名称/图像只在本机出现。请分别选择项目对应、图像相符、相对布局是否无明显矛盾，再“保存结果并关闭”。默认均为未核对，叉号关闭不记录确认；可以保留不能判断的项目。快照只取实际 IFolderView 的前 N 项，不创建或移动桌面文件，不能保证覆盖所有类型。

每项使用同一个保留的 child PIDL 和 IShellFolder 取得名称、图像和位置，虚拟项目不要求文件路径。编号只在本次随机 UUID 快照内有效，不能跨快照追踪。报告不导出名称、路径、PIDL 或图像，保留 API 错误、原始位置、显示条件和逐编号人工选择；Shell 通用类型图标是否为占位性质保持未知，应用不生成替代图标。

GetItemPosition 的值是 Shell 视图内项目左上锚点，不是图像中心、客户区点或屏幕点；逻辑/物理单位、图像/标签矩形及屏幕映射仍未知。本版不执行坐标转换，没有逐项补偿或 DPI 乘除。窗口内的图标只是核对样本，不是桌面覆盖层。监视器范围、工作区、缩放与窗口 DPI 按各 API 返回记录；失败字段为 null，系统缩放不变。

必须具备可见窗口站、接收输入的当前桌面、同会话 Shell 宿主，否则明确报告环境错误，不发起 Shell 查询。报告/窗口正常结束 exit 0 不代表验收通过；1 为 API/部分读取失败，2 参数错误，3 非交互环境，4 报告写入失败，5 窗口失败或显示配置变化。测试用的合成记录不是真实桌面证据。

本轮拖动复查仍应从输入标识 `199eb44687aeac63d44b4f86b76e4e96bc5e1f25b60ccafff79b14dd8f698f9e` 的原定时器包启动；不要把新探针包中重编译的沙盒当作原包人工结果。两个程序与各自输入/EXE 哈希分别记录。

## W3 非隐藏镜像开发预览：标记、静态副本、重力

新增 `bin/desktop_mirror_preview.exe --report <新文件.json>`，标题“桌面镜像开发预览——保留原图标”。请从普通登录用户 PowerShell 启动，报告路径必须不存在。每次开始先显示 3–5 个绿色项目锚点/编号；控制面板可立即停止、保存并停止，每阶段 90 秒自动停止桌面绘制，结果面板保留供填写。Esc 只在控制窗口收到键盘输入时有效。无需运行 W2 探针。

每次启动通过原有读取函数取得新 Shell 快照和图像缓存。当前只支持单屏、同会话 PMv2 的桌面视图，要求从 IShellView::GetWindow 下找到唯一直接 SysListView32、同进程、LVS_NOSCROLL、无滚动条、非 RTL；不满足就拒绝并记录错误。此 Shell 实现约定被隔离为受限适配器，不能推及其他 Windows/自定义 Shell。原始锚点按该已检查无滚动视图约定映射到其 ListView 客户区，以 MapWindowPoints 单点转换到屏幕再到预览客户区；返回零时区分 GetLastError。没有任意祖先坐标、逐项补偿、Y 翻转或将原始点乘以 1.25。

绘制使用 D3D11 硬件设备、DXGI 预乘 alpha 交换链、Direct2D 像素单位与 DirectComposition。D2D 明确设置 96 DPI/PIXELS，使绘制坐标与交换链像素对应；场景坐标仅通过共享 coordinates 函数按实际预览窗口 DPI 转成 DIP。图标副本阶段切换 D2D 为 DIPS 并使用实际预览窗口 DPI。历史窗口 DPI 120 与监视器缩放 API 100% 的差异仍未解释，缩放接口不参与本次映射。绿色十字标示项目锚点，编号统一向右下偏移；不是图像中心或 Explorer 图像边界。

自有窗口不绑定 Explorer、不永久置顶、不捕获鼠标。初次只把自己的窗口放到 Shell 根窗口之前；普通应用层级须人工验证。绘制区域限制在少量标记小块，透明失败也不能绘制整屏实色背景。窗口样式不是鼠标穿透验收证据。显示/宿主条件变化或设备失效时关闭原型；不重建宿主或改系统设置。

2026-11-12 的标记包在当前 Windows 10.0.19045.6466 x64 单屏、1920×1080 / 工作区 1920×1030、PMv2/120 DPI 配置完成基础人工检查。新预览仅在这一 OS/显示配置匹配时提供后续按钮；这不是硬件身份或其他平台能力证明，每次仍需显式确认当前标记正常。其他配置保持标记模式，不自动开放副本。

一次顺序检查：查看绿色标记 → 点击“当前标记正常，显示副本” → 检查本机 3–5 个副本的图像、编号和自定义位置，第一项选“符合” → 点击“静态副本正常，播放重力” → 检查下落/碰撞、暂停/继续、重置与普通应用/任务栏 → 分别填写结果 → 保存并停止。每次显式进入下一阶段重新开始 90 秒保护；到时只停止桌面绘制，保留面板便于保存。无需再次运行只读样本探针。

副本图像来自同一快照缓存 HBITMAP，一次经 WIC 转为预乘 alpha 的 D2D 位图，绘制不重新枚举 Shell、解码或创建纹理。DPP 自定义尺寸 48×48 DIP，左上角放在转换的项目锚点，中心通过 coordinates 的 rectCenter 得到；这不等于 Explorer 原始图像边界。碰撞用共享 GravityMode 默认 90% 图像框，标签不碰撞。图形带 DPP 编号和自定义轮廓，不画真实标签。没有文件路径参与纹理关联。用户报告此前 64 DIP 副本比原图标大，因此缩小默认尺寸，仍不宣称与原图标同尺寸。

重力复用 Playground/GravityMode/Box2D 3.1.1，显式确认本次静态副本之前不能启动。共享 FrameTimer 只在周期变化时重设，活跃 15 ms、静止 200 ms；定时周期不是呈现 FPS。窗口区域随副本的保守边界更新，只改自己的窗口区域；当前没有对这种区域更新成本做 GPU/呈现性能验收。

默认不捕获输入。静态与播放确认后，还必须显式点击“进入交互”，才能抓取、拖动和松开抛掷 DPP 副本。交互仅限自有窗口区域，不安装全局钩子；只有成功抓取物体才 SetCapture，松键只释放本程序捕获。失焦、切换应用、点击面板、取消消息、显示变化、异常或关闭会取消抓取。失焦后恢复不接管鼠标的播放，重新进入必须再点按钮。另有“退出交互”和“立即停止”，Esc 只在对应窗口收到键盘时有效。

第五项用于人工核对拖拽、抛掷与输入释放；从未进入交互时不能把该项记为通过。报告记录进入次数、指针事件、取消与停止后的自有捕获状态，API/命令计数不等于人工验收，也不证明全部资源无泄漏。只拖动带 DPP 标识的副本，不拖动真实图标。精确屏幕对齐、持久层级与正式真实桌面模式仍未完成。
